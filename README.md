# 🤖 ربات تلگرام - سیستم امتیازات و دعوت

ربات تلگرام حرفه‌ای برای مدیریت کاربران، امتیازات و سیستم دعوت با **پنل ادمین قوی**.

## ✨ ویژگی‌ها

- ✅ **سیستم تأیید عضویت** - تأیید اجباری در کانال‌های مشخص
- ✅ **سیستم امتیازات** - کاربران امتیاز جمع‌آوری و خرج می‌کنند
- ✅ **سیستم دعوت** - هر دعوت موفق = +1 امتیاز
- ✅ **محصولات دینامیک** - ادمین می‌تونه بخش‌ها و محصولات رو مدیریت کنه
- ✅ **پنل ادمین** - اضافه/حذف محصول، پیام گروهی، مشاهده آمار
- ✅ **ذخیره‌سازی SQLite** - تمام داده‌ها محفوظ می‌مانند
- ✅ **آمار کاربری** - نمایش امتیازات و دعوت‌های هر کاربر

## 🚀 شروع سریع

### الزامات
- Python 3.7+
- توکن ربات از [@BotFather](https://t.me/BotFather)

### نصب

1. **کلون کردن مخزن:**
```bash
git clone <your-repo-url>
cd telegram-bot
```

2. **نصب کتابخانه‌ها:**
```bash
pip install -r requirements.txt
```

3. **تنظیم فایل اصلی (`telegram_bot.py`):**

فایل رو باز کنید و این بخش‌ها رو تغییر بدید:
```python
# تنظیمات
BOT_TOKEN = "YOUR_BOT_TOKEN_HERE"  # توکن ربات
CHANNEL_1 = "phdjld"  # کانال اول (بدون @)
CHANNEL_2 = "poruirlae"  # کانال دوم (بدون @)
ADMIN_ID = 123456789  # آیدی ادمین (عددی)
```

4. **اجرای ربات:**
```bash
python telegram_bot.py
```

## 📚 نحوه استفاده

### برای کاربران عادی:
1. `/start` - شروع با ربات
2. ✅ **تأیید عضویت** - عضویت در کانال‌ها + تأیید
3. 🎁 **محصولات** - خریداری با امتیاز
4. 👥 **دعوت دوستان** - دریافت لینک شخصی
5. 📊 **آمار من** - مشاهده امتیازات

### برای ادمین:
- ⚙️ **ادمین پنل** - دسترسی دادن به ADMIN_ID
  - ➕ اضافه کردن محصول
  - 📝 ویرایش/حذف محصول
  - 📢 ارسال پیام گروهی
  - 📊 مشاهده آمار کل

## 📊 ساختار دیتابیس

```
users          → اطلاعات کاربران (امتیاز، کد دعوت، وضعیت تأیید)
products       → محصولات/بخش‌ها (نام، قیمت، توضیح)
referrals      → ثبت دعوت‌های موفق
admin_messages → پیام‌های ادمین
```

## 🔧 تنظیمات پیشرفته

### تغییر نام کانال‌ها:
```python
CHANNEL_1 = "your_channel_1"
CHANNEL_2 = "your_channel_2"
```

### تغییر مقدار امتیاز برای دعوت:
در تابع `start_handler`، این خط رو تغییر بدید:
```python
add_points(referrer_id, 1)  # تعداد امتیاز برای دعوت
```

## 📝 مثال محصول

هنگام اضافه کردن محصول:
```
نام: اکانت رایگان
هزینه: 1
توضیحات: یک اکانت رایگان
متن دکمه: 🎁 دریافت رایگان
```

## ⚠️ نکات مهم

- **ربات باید مدیر کانال‌ها باشه** (برای بررسی عضویت)
- **فایل `bot_data.db` خودکار ایجاد می‌شود**
- **آیدی ادمین عددی است** (از [@userinfobot](https://t.me/userinfobot) بپرسید)
- **توکن ربات را محفوظ نگه دارید** (عمومی نکنید)
